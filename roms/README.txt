Put the Apple-1 Integer BASIC image here as:  apple1basic.bin

  * exactly 4096 bytes, the image that loads at $E000 (started with E000R), or
  * a text hex dump of $E000-$EFFF in Woz Monitor format ("E000: 4C B0 E2 ..."),
    saved under the same name or passed with -DBASIC_SRC=/path/to/file

This project does not ship the BASIC image.
