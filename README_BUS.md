# Apple 1 Pico External 5V Hardware Expansion Bus

This update adds a 5V-compatible external 6502 expansion bus to the Apple 1 Pico emulator using a hybrid execution model: internal RAM/ROM runs at full speed in Pico SRAM, while accesses to the external expansion windows drive real 5V bus hardware synchronized to a continuous 1 MHz `PHI2` clock.

---

## 1. Hardware Architecture & Pinout (GPIO 2–16)

`GPIO 0` and `GPIO 26` remain untouched so `aci.c` / `aci.h` cassette audio I/O continues working without conflict.

| Pico GPIO | Connected IC / Pin | Signal | Notes |
| :--- | :--- | :--- | :--- |
| **GPIO 2 – 9** | 74AHCT573 (D0–D7) & SN74LVC4245A (B1–B8) | Shared `D0–D7` / `A0–A7` | Multiplexed 8-bit data & address bus |
| **GPIO 10** | 74AHCT573 #1 (`LE`) | `LE_LOW` | Latches lower address byte (`A0–A7`) |
| **GPIO 11** | 74AHCT573 #2 (`LE`) | `LE_HIGH` | Latches upper address byte (`A8–A15`) |
| **GPIO 12** | SN74LVC4245A (`DIR`, Pin 2) | `DIR` | `HIGH` = Read (`A -> B`), `LOW` = Write (`B -> A`) |
| **GPIO 13** | SN74LVC4245A (`OE#`, Pin 22) | `OE#` | Active LOW transceiver enable |
| **GPIO 14** | Expansion Slot `PHI2` | `PHI2` | Continuous 1 MHz clock generated by hardware PWM |
| **GPIO 15** | Expansion Slot `R/W` | `R/W` | `HIGH` = Read, `LOW` = Write |
| **GPIO 16** | Expansion Slot `RESET#` | `RESET#` | Active LOW system reset |

### SN74LVC4245A Power Rail Reminder
- **Pin 1 (`VCCA`)**: Connect to **+5V** (Apple 1 expansion slot side — Port A).
- **Pins 23 & 24 (`VCCB`)**: Connect to **+3.3V** (Raspberry Pi Pico side — Port B).
- Tie all **5V GND** and **Pico GND** pins together securely.

## 2. PHI2 Clock & PWM Edge Synchronization Note

`GPIO 14` is configured as a free-running **1 MHz hardware PWM output** (`wrap = 124` at 125 MHz system clock, `level = 62` for a 50% duty cycle):
- **Counter `0 .. 61`**: `PHI2` is **HIGH** (valid data transfer phase).
- **Counter `62 .. 124`**: `PHI2` is **LOW** (address setup phase).

### Synchronized Bus Cycle Timing (`expansion_bus_read` / `expansion_bus_write`)
Even though `PHI2` runs autonomously in hardware, both `expansion_bus_read()` and `expansion_bus_write()` synchronize their bus phases directly against the PWM slice counter (`pwm_get_counter()`):
1. **Address Setup (`PHI2` LOW):** Both functions wait until the PWM counter enters the `PHI2` LOW window (`counter >= 62`) before latching `A0–A7` and `A8–A15` into the 74AHCT573 chips and setting `R/W`.
2. **Data Sampling / Hold (`PHI2` HIGH):** Both functions then wait until late in the `PHI2` HIGH phase (`counter >= 52`, roughly 80 ns before the falling edge at tick 62) before sampling incoming data on reads or releasing the bus on writes. This gives external 5V cards proper address setup time and data hold time—mirroring a true hardware 6502 bus cycle.

## 3. Memory Map Layout

| Address Range | Region | Handler |
| :--- | :--- | :--- |
| `$0000 – $BFFF` | `K_RAM` | Internal Emulated RAM (48 KB) |
| `$C000 – $C0FF` | `K_ACI` | Emulated Apple Cassette Interface (`aci.c`) |
| `$C100 – $C1FF` | `K_ROM` | Emulated Cassette ROM |
| **`$C200 – $CFFF`** | **`K_EXT`** | **External Hardware Expansion Window 1** |
| `$D000 – $D0FF` | `K_PIA` | Emulated Motorola 6821 PIA |
| **`$D100 – $DFFF`** | **`K_EXT`** | **External Hardware Expansion Window 2** |
| `$E000 – $EFFF` | `K_RAM` | Apple 1 BASIC ROM |
| `$F000 – $FEFF` | `K_RAM` | Reserved for future ROM images |
| `$FF00 – $FFFF` | `K_RAM` | Wozmon ROM (`wozmon.h`) |

## 4. Testing with Included 6502 Assembly Routines

- **`asm/bus_test.asm` (`$0300`)**: Writes 8 test bytes (`$11, $22, $44, $88, $FF, $00, $AA, $55`) to `$C200–$C207`, reads them back across the SN74LVC4245A transceiver, and stores the results at `$0200–$0207` so you can verify them in Wozmon with `0200.0207`.
- **`asm/bus_scanner.asm` (`$0380`)**: Scans `$C200–$CFFF` for any responding expansion card returning non-`$FF` data.
